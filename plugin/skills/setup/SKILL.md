# channelcollab 設定精靈

每位成員有一個自己的 Discord Bot，背後是他自己電腦上的 Claude Code。這個精靈把 Bot 裝好、設好、啟動。對象多半是不熟技術的企劃：**一次只做一步、用白話說明、做完一步回報結果再往下**。

本 plugin 的總控腳本（下文簡稱「總控」）：

```
node "${CLAUDE_PLUGIN_ROOT}/scripts/channelcollab.mjs" <子命令>
```

匯入交付檔用建 Bot 工具的腳本：

```
node "${CLAUDE_PLUGIN_ROOT}/skills/create-bot/scripts/create-bot.mjs" import-handoff "<交付檔路徑>" --json
```

路徑一律加雙引號。指令只用「`node "…" 參數`」這種形式，不要用 `&&`、`$env:`、heredoc，這樣 Bash 和 PowerShell 都能執行。

**HOME**：Bot 的資料（設定檔、log、執行環境）放在 HOME 資料夾，預設 `%USERPROFILE%\.channelcollab`，有環境變數 `CHANNELCOLLAB_HOME` 時用它。一般使用者不用管這個；使用者明確說要用別的資料夾時（例如同一台電腦跑第二隻 Bot），所有指令都加 `--home "<資料夾>"`。

## 安全守則（一律遵守）

1. **交付檔和 `config.json` 裡有明文 Bot token。絕對不要用 Read、cat、type、Get-Content 或任何方式打開、讀取、顯示這兩個檔案**，只能把路徑交給腳本處理。腳本的輸出不含 token。
2. 不要叫使用者貼 token。使用者不小心把 token 貼進對話時，不要複述，請他通知管理員重新產生（Reset Token）並重給交付檔（自己建的 Bot 就自己到 Developer Portal 按 Reset Token）。
3. 不要用 `bypassPermissions`。
4. **PIN 只能由使用者自己在跳出的主控台視窗輸入**：不要請使用者把 PIN 打在對話裡，也不要把 PIN 放進任何指令參數。

## 步驟 0：問用途

先用一兩句話說明：這個精靈會把你自己的 Discord Bot 裝好，Bot 背後是這台電腦上的 Claude Code。然後用 AskUserQuestion 問用途（單選）：

| 選項 | 說明（放在選項的 description） |
|---|---|
| **只用私訊（個人遠端 Claude）** | 在手機或別台電腦上私訊自己的 Bot，等於遠端用這台電腦的 Claude Code。不參與團隊頻道 |
| **團隊頻道協作** | 在團隊的 Discord 頻道 @ Bot 交辦事情，Bot 開討論串處理，也能和其他人的 Bot 交棒 |
| **兩者都要** | 團隊頻道協作，另外也能私訊自己的 Bot |

依選擇走下面對應的流程，並告訴使用者大概要做哪幾步（約 5～10 分鐘）。三種流程的步驟 1、2 相同。

> 選了「只用私訊」或「兩者都要」時，**在開始前就說明私訊的資安**（見「私訊資安說明」），讓使用者知道後再繼續。

### 私訊資安說明（選了私訊的流程都要講）

- **只有主人能用**：Bot 只接受主人（你自己的 Discord 帳號）的私訊，別人私訊會被擋。
- **私訊等於遠端操作這台電腦**：能用私訊的人就能叫 Claude 讀檔、改檔、執行指令（要改檔或執行指令時一樣會跳權限按鈕）。
- **一定要設 PIN**：沒有 PIN，私訊不會開放；PIN 輸錯 3 次整隻 Bot 會鎖住，要回電腦解除。
- **Discord 帳號要開兩步驟驗證**（使用者設定 → 我的帳號 → 啟用兩步驟驗證），帳號被盜等於電腦被遠端操作。

## 步驟 1：檢查 Node（三種流程都一樣）

執行 `node --version`。

- **找不到 node 指令，或版本低於 v22**：**不要自己安裝**。請使用者：
  1. 開一個終端機（開始選單搜尋「終端機」或「PowerShell」），執行 `winget install OpenJS.NodeJS.LTS`；
  2. 裝完後**關掉所有終端機和 Claude Code，重新開啟**（新的 PATH 才會生效）；
  3. 再執行一次 `/channelcollab:setup`。

  說明完就停在這裡。
- 版本是 v22 以上：執行總控 `check`，看目前狀態。
  - 已經有 token，而且有頻道綁定或私訊設定（`模式：` 不是「還沒設定」）、Bot 也在執行：告訴使用者已經設定好了，問他想重做哪一步（重新匯入、改綁定、開私訊、重建捷徑），只做那一步。
  - npm 顯示找不到：請使用者重新安裝 Node（同上）。

## 步驟 2：安裝執行環境（三種流程都一樣）

執行總控 `install-runtime`。第一次要下載約 300 MB，可能要幾分鐘：**指令逾時請設成 10 分鐘**，執行前先告訴使用者要等一下。

- 失敗多半是網路問題（公司網路擋 registry.npmjs.org、代理伺服器）。把錯誤訊息的重點轉述給使用者，請他確認網路後再試；仍不行就請他聯絡管理員。

## 流程 A：只用私訊（個人遠端 Claude）

順序：步驟 1 → 2 → A3 → A4 → A5 → A6 → A7 → A8 → A9。**跳過綁頻道和名冊。**

### A3：取得 Bot（匯入交付檔，或自己建）

先問使用者手上有沒有管理員給的交付檔（`.json`）：

- **有交付檔**：照下方「共用步驟：匯入交付檔」做。
- **沒有交付檔**：改用 `/channelcollab:create-bot`，選「**只給自己私訊用**」。那個流程會帶使用者在 Developer Portal 建 Bot、把 token 存進 HOME、產生權限精簡的邀請網址，並把 Bot 邀進使用者自己的伺服器（沒有的話教他建一個私人伺服器）。做完回到這裡的 A4。
  - 這台電腦的 HOME 已經有別的 Bot 時（`check` 顯示 token 已設定），用另一個 HOME（例如 `%USERPROFILE%\.channelcollab-personal`），之後每個指令都加 `--home`。

**Discord 的限制**：要私訊 Bot，你和 Bot 至少要在同一個伺服器。只用私訊的人可以把 Bot 邀進**自己建的私人伺服器**（只有自己一個人也可以）。用交付檔的話，管理員通常已經把 Bot 邀進團隊伺服器，你也在那個伺服器裡，就不用再做。

### A4：主人 ID

見下方「共用步驟：主人 ID」。**只用私訊時主人一定要設**（私訊只接受主人）。

### A5：設定 PIN（必要，不能跳過）

只用私訊時 **PIN 是必要的**：沒有 PIN，私訊不會開放。不要用 AskUserQuestion 問要不要設，直接說明後設定：

1. 告訴使用者「等一下會跳出一個黑色視窗，請在那個視窗輸入兩次 PIN（建議 6 位數字，畫面只會顯示 *），**不要把 PIN 打在這裡的對話**」。
2. 執行總控 `set-pin`（**指令逾時設 10 分鐘**）。指令會等視窗關閉，結果顯示「✅ PIN 已設定」或「沒有變更」。
3. 顯示「沒有變更」（使用者關掉視窗或兩次不一致）時，說明 PIN 是必要的，再執行一次。使用者堅持不設時，停在這裡，告訴他之後用 `/channelcollab:setup` 或 `/channelcollab:bind` 設 PIN 再繼續。

### A6：私訊的工作資料夾與權限模式

一次問清楚：

| 項目 | 說明 |
|---|---|
| 工作資料夾 | Claude 在私訊裡讀寫檔案的地方。沒有特定資料夾時，建議在「文件」底下建一個 `channelcollab-work`（用 `node -e "require('fs').mkdirSync(process.argv[1],{recursive:true})" "<路徑>"` 建立） |
| 權限模式 | 用 AskUserQuestion：`default`（建議：改檔、執行指令都要在 Discord 按允許）／`acceptEdits`（改工作資料夾裡的檔案不用問，執行指令仍要問）／`plan`（只討論不動手）。**不允許 `bypassPermissions`** |
| 模型 | 用 AskUserQuestion：sonnet（建議，均衡）／haiku（最便宜）／opus（最強、最貴） |

執行總控：

```
bind --dm --cwd "<工作資料夾>" --model <模型> --permission-mode <模式>
```

### A7：啟動 Bot

見下方「共用步驟：啟動 Bot」。`status` 應該顯示「模式：只用私訊」、「綁定的頻道：無（只用私訊，不需要…）」、私訊開啟、PIN 已設定。

### A8：私訊 Bot 測一次

請使用者在 Discord（手機或電腦都可以）：

1. 到和 Bot 共同的伺服器，在成員列表點 Bot →「傳送訊息」（或從私訊清單找到它）。
2. 傳一則訊息，例如「你好，現在的工作資料夾是哪裡？」。
3. 第一次會出現 🔒 和「解鎖」按鈕：按下去輸入 PIN。解鎖後剛剛的訊息會接著處理，訊息上會出現 👀 → ⚙️ → ✅，Bot 會回覆。
4. 打 `/` 會跳出指令選單（選這隻 Bot 底下的），例如 `/help`、`/status`；也可以打 `!help`。斜線指令剛註冊時，Discord 可能要幾分鐘才出現，看不到就先用 `!help`，或重開 Discord。

沒反應時：執行總控 `status` 看「最近的錯誤」；常見原因是和 Bot 沒有共同伺服器、主人 ID 不是自己、PIN 還沒輸入。

### A9：建立捷徑

見下方「共用步驟：捷徑」。

### 完成（只用私訊）

用簡短清單告訴使用者：

- Bot 名稱、主人、私訊的工作資料夾與權限模式、捷徑的位置。
- 怎麼用：私訊 Bot 就能交辦；🔒 時按「解鎖」輸入 PIN（解鎖後一段時間內不用再輸入）。
- 指令：打 `/` 選這隻 Bot 的指令（`/help`、`/status`、`/model`、`/clear`、`/resume`、`/skill` …），或打 `!help`。
- 再提醒一次資安：只有主人能用、等於遠端操作這台電腦、Discord 帳號要開兩步驟驗證。
- **之後想加入團隊頻道，用 `/channelcollab:bind` 綁頻道就好，不用重新 setup**（Bot 要先被邀進那個伺服器）。
- 交付檔還沒刪的話，再提醒一次。

## 流程 B：團隊頻道協作

順序：步驟 1 → 2 → 共用步驟：匯入交付檔 → 共用步驟：主人 ID → B5 → B5-1 → B5-2 → 共用步驟：啟動 Bot → 共用步驟：捷徑 → 完成。

### B5：綁定第一個頻道

Bot 只在綁定的頻道回應。一次問清楚（自由輸入的項目直接在對話裡一起問）：

| 項目 | 說明 |
|---|---|
| 頻道 ID | Discord 上對頻道名稱按右鍵 →「複製頻道 ID」（需要開發者模式，見「主人 ID」）。是一串 17～20 位數字 |
| 工作資料夾 | Bot 在這個資料夾裡讀寫檔案，例如專案的資料夾。企劃沒有特定資料夾時，建議在「文件」底下建一個 `channelcollab-work`（用 `node -e "require('fs').mkdirSync(process.argv[1],{recursive:true})" "<路徑>"` 建立） |
| 模型 | 用 AskUserQuestion：sonnet（建議，均衡）／haiku（最便宜、適合簡單問答）／opus（最強、最貴） |

權限模式不用問，一律用 `default`（每次 Bot 要改檔或執行指令都會在 Discord 出現按鈕，由主人確認）。使用者主動要求別的模式時，改用 `/channelcollab:bind`。

執行總控：

```
bind --channel <頻道ID> --cwd "<工作資料夾>" --model <模型> --permission-mode default
```

### B5-1：設定 PIN（建議）

PIN 是主人在 Discord 上按「允許」、以及用私訊時要輸入的密碼。說明後用 AskUserQuestion 問要不要現在設定（建議設定）。

- 要設定：先告訴使用者「等一下會跳出一個黑色視窗，請在那個視窗輸入兩次 PIN（建議 6 位數字，畫面只會顯示 *），**不要把 PIN 打在這裡的對話**」，再執行總控 `set-pin`（**指令逾時設 10 分鐘**）。指令會等視窗關閉，結果顯示「✅ PIN 已設定」或「沒有變更」。
- **絕對不要**請使用者把 PIN 告訴你，也不要把 PIN 放進任何指令參數。
- 不設定：告訴使用者之後可以雙擊捷徑「設定 <Bot 名稱> PIN」或用 `/channelcollab:bind` 再設定；沒有 PIN 時私訊不會開放。

### B5-2：要不要開私訊（可以選不開）

私訊讓主人在手機上直接私訊自己的 Bot（不用 @、不用開討論串），像簡化版的 Claude Code。用 AskUserQuestion 問要不要開，選項包含「不開」。選開的話先講「私訊資安說明」。

- 要開：工作資料夾預設用**B5 綁定頻道的資料夾**（使用者也可以指定別的）。執行總控：
  ```
  bind --dm --cwd "<工作資料夾>" --model <B5 的模型> --permission-mode default
  ```
  還沒設 PIN 時：說明私訊要有 PIN 才會開放，回到 B5-1 設定（使用者仍不設，就提醒之後再設）。
- 不開：之後可以用 `/channelcollab:bind` 開。

### 完成（團隊頻道協作）

用簡短清單告訴使用者：

- Bot 名稱、主人、綁定的頻道與工作資料夾、捷徑的位置。
- 怎麼用：在綁定的頻道 **@Bot 名稱** 加上要交辦的事，Bot 會開一個討論串回覆；之後在討論串裡直接講話就好。
- 訊息上的表情：👀 收到（排隊中）、⚙️ 處理中、⏳ 等待確認、✅ 完成、❌ 失敗。
- Bot 要改檔或執行指令時會出現按鈕，只有主人能按（設了 PIN 時要輸入 PIN；2 分鐘沒按會改成私訊卡片，稍後核准）。
- 討論串裡打 `/` 會跳出指令選單：**同一個伺服器有好幾隻 Bot 時，選單會依 Bot 分組，請選自己這隻 Bot 底下的指令**。也可以打 `!help`。
- 開了私訊的話：在 Discord 點自己的 Bot →「傳送訊息」就能直接交辦。
- 只有自己和名冊上的人、Bot 能叫這個 Bot（白名單）；要讓別人也能叫，用 `/channelcollab:roster` 加進名冊。
- 常用指令：`/channelcollab:status`（狀態）、`/channelcollab:stop`（停止）、`/channelcollab:start`（啟動）、`/channelcollab:bind`（綁更多頻道）。
- 交付檔還沒刪的話，再提醒一次。

## 流程 C：兩者都要

和流程 B 相同，但：

- 開始前先講「私訊資安說明」。
- **B5-1 的 PIN 改成必要**：照 A5 的做法直接設定，不問要不要。
- **B5-2 一定要開私訊**（不問要不要開，只問工作資料夾，預設用 B5 的資料夾；權限模式和模型沿用 B5，使用者要別的再改）。
- 啟動後除了在頻道 @Bot，也照 A8 請使用者私訊 Bot 測一次。
- 完成時兩種用法都說明（合併流程 A、B 的完成清單）。

## 共用步驟：匯入交付檔

交付檔是管理員私下傳給使用者的 `.json` 檔，例如 `小明-bot.json`。

1. 呼叫時有帶參數就把它當交付檔路徑；沒有就問使用者檔案放在哪裡（常見是「下載」資料夾）。可以用 Glob 在 `%USERPROFILE%\Downloads` 找 `*-bot.json` 來確認檔案存在，**但不要打開它**。
2. 匯入：`import-handoff "<路徑>" --json`（上方的建 Bot 腳本）。腳本會向 Discord 驗證 token，再把 token、主人 ID 寫進 HOME；交付檔附的名冊條目（通常是這個 Bot 自己）合併進名冊，不覆蓋原有的。最後一行 `RESULT {...}` 有 `botName`、`ownerId`、`rosterCount`。
3. 依結果處理：
   - **「已經有另一個 Bot 的 token」**：這台電腦的 HOME 已經有別的 Bot。不要自己加 `--replace`。問使用者：要取代原本的 Bot（加 `--replace` 重跑），還是用另一個資料夾跑第二個 Bot（之後每個指令都加 `--home`）。
   - **401／token 無效**：交付檔過期了（管理員重設過 token）。請使用者向管理員要新的交付檔。
   - **連不到 Discord**：請使用者確認網路可以連 discord.com。
4. 匯入成功後，用 AskUserQuestion 問要不要現在刪除交付檔（建議刪除：裡面是明文 token，設定已經存好了）。同意就執行：
   ```
   node -e "require('fs').rmSync(process.argv[1])" "<交付檔路徑>"
   ```
   並提醒：如果檔案是用 Discord 私訊或其他聊天工具傳的，也把那則訊息刪掉。

## 共用步驟：主人 ID

主人是 Bot 的擁有者，只有主人能在 Discord 上按權限按鈕（允許 Bot 改檔、執行指令），也只有主人能私訊 Bot。

- `RESULT` 的 `ownerId` 有值（或 `check` 顯示主人已設定）：告訴使用者「主人已設定為 <ID>」，跳到下一步。
- 沒有：請使用者提供自己的 Discord 使用者 ID，教他取得方式：
  1. Discord 左下角齒輪「使用者設定」→「進階」→ 打開「開發者模式」；
  2. 在任何地方對自己的頭像按右鍵 →「複製使用者 ID」。

  拿到 17～20 位數字後執行總控 `set-owner <ID>`。

## 共用步驟：啟動 Bot

執行總控 `start`（會等 Bot 上線，最多 90 秒；**指令逾時設 3 分鐘**；runtime 需要更新時會先自動安裝，那時要更久）。

- 出現「✅ Bot 已上線：登入成 …」就成功了，再執行總控 `status` 給使用者看整體狀態（`模式：` 那一行要符合使用者選的用途）。
- 失敗時，腳本會印出最近的錯誤。常見原因：token 失效（向管理員要新的交付檔，自己建的就重新 Reset Token）、網路連不到 discord.com、Message Content Intent 沒開。

## 共用步驟：捷徑

執行總控 `shortcut`，在桌面建立四個檔案，**檔名帶 Bot 名稱**（同一台電腦有好幾隻 Bot 也不會互相覆蓋）：「啟動 <Bot 名稱>.bat」「停止 <Bot 名稱>.bat」「設定 <Bot 名稱> PIN.bat」「解除 <Bot 名稱> 鎖定.bat」（後兩個：設定或更換 PIN；PIN 輸錯 3 次被鎖定時解除）。使用者想放別的資料夾時加 `--dir "<資料夾>"`。把腳本印出的完整路徑告訴使用者。之後有兩種方式啟動、停止 Bot，效果一樣：

- 雙擊「啟動／停止 <Bot 名稱>」，看到結果後按任意鍵關閉視窗；
- 在 Claude Code 輸入 `/channelcollab:start`、`/channelcollab:stop`。

Bot 都是在背景獨立執行，關掉視窗或 Claude Code 都不會停。
