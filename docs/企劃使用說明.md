# channelcollab 企劃使用說明

channelcollab 讓你在 Discord 上把工作交給**自己的 Bot**。Bot 背後是你電腦上的 Claude Code，用你自己的登入、設定和工作資料夾。在頻道裡 @ 你的 Bot 交辦事情，它會開一個討論串處理，做完回報；要改檔或執行指令前，會先在 Discord 上請你按按鈕確認。

不想參與團隊頻道、只想把 Bot 當成「手機上的私人 Claude」也可以，見第 6 節「只用私訊」。

整個安裝大約 10 分鐘。

---

## 1. 事前準備

| 項目 | 怎麼確認／取得 |
|---|---|
| Claude Code 已安裝並登入 | 開終端機輸入 `claude`，能正常對話就可以 |
| **Node 22 以上** | 開終端機輸入 `node --version`，顯示 `v22.x.x` 以上就可以。顯示找不到指令或版本比較舊時，執行下面的安裝指令 |
| 管理員給你的**交付檔** | 一個 `.json` 檔（例如 `小明-bot.json`），管理員會私下傳給你。**裡面是你的 Bot 的密碼（token），不要轉傳給任何人** |
| Discord 開發者模式 | Discord 左下角齒輪「使用者設定」→「進階」→ 打開「開發者模式」。打開後才能複製頻道 ID |
| 要讓 Bot 工作的頻道 | 問管理員或工程師要用哪個頻道（只用私訊的人不需要，見第 6 節） |

**安裝 Node**（只要做一次）：開「終端機」或「PowerShell」，執行

```
winget install OpenJS.NodeJS.LTS
```

裝完後**關掉所有終端機和 Claude Code 再重新開啟**，新安裝的 Node 才找得到。

---

## 2. 安裝 plugin

在終端機執行下面兩行（只要做一次）：

```
claude plugin marketplace add jijia-Huang/channelcollab
claude plugin install channelcollab@channelcollab
```

也可以在 Claude Code 對話裡輸入 `/plugin marketplace add jijia-Huang/channelcollab`，再用 `/plugin` 找到 channelcollab 安裝。

裝好後重開 Claude Code。

---

## 3. 執行設定精靈

在 Claude Code 輸入：

```
/channelcollab:setup
```

精靈一開始會問你的**用途**：「只用私訊（個人遠端 Claude）」、「團隊頻道協作」或「兩者都要」，再依你的選擇走不同的步驟。選「只用私訊」的步驟見第 6 節；下面是「團隊頻道協作」的步驟（「兩者都要」再加上私訊，PIN 變成必要）：

1. **檢查 Node**：版本不夠時會請你先安裝（見第 1 節）。
2. **安裝執行環境**：第一次要下載約 300 MB，等 1～3 分鐘。
3. **匯入交付檔**：告訴它檔案在哪裡（例如「在下載資料夾」）。匯入後它會問你要不要刪掉交付檔，**請刪掉**；如果交付檔是透過 Discord 私訊傳的，也把那則訊息刪掉。
4. **主人 ID**：通常交付檔已經帶了。沒有的話，對自己的頭像按右鍵 →「複製使用者 ID」貼給它。主人是唯一能按權限按鈕的人。
5. **綁定頻道**：對頻道名稱按右鍵 →「複製頻道 ID」貼給它；再告訴它工作資料夾（沒有特定資料夾就讓它幫你建一個）和模型（一般選 sonnet）。
6. **設定 PIN**（團隊頻道協作時建議設定；有開私訊時必要）：會跳出一個黑色視窗，請**你自己在那個視窗**輸入兩次 PIN（建議 6 位數字，畫面只顯示 *）。之後在 Discord 按「允許」或用私訊時要輸入它。PIN 不會經過 Claude，也不會出現在對話裡。
7. **要不要開私訊**：開了之後可以在手機上直接私訊 Bot（見第 5 節）。工作資料夾預設和第一個頻道相同。要先設 PIN 才會生效。可以選不開。
8. **啟動 Bot**：看到「✅ Bot 已上線」就完成了。
9. **桌面捷徑**：在桌面建立四個檔案，檔名帶你的 Bot 名稱，例如 Bot 叫「小華Bot」時是「啟動 小華Bot」「停止 小華Bot」「設定 小華Bot PIN」「解除 小華Bot 鎖定」，之後雙擊就能用。同一台電腦有好幾隻 Bot 時，各自的檔案不會互相覆蓋。

## 4. 日常使用

### 啟動與停止 Bot（兩種方式，效果一樣）

| | 方式一：桌面雙擊 | 方式二：在 Claude Code 輸入指令 |
|---|---|---|
| 啟動 | 雙擊桌面的「**啟動 <Bot 名稱>**」 | `/channelcollab:start` |
| 停止 | 雙擊桌面的「**停止 <Bot 名稱>**」 | `/channelcollab:stop` |
| 看狀態 | — | `/channelcollab:status` |

- 啟動後會顯示「✅ Bot 已上線：登入成 …」、模式（只用私訊／團隊頻道協作／兩者）和綁定的頻道。用雙擊的話，看完按任意鍵關閉視窗。
- Bot 在**背景**執行：關掉那個視窗、關掉 Claude Code 都不會停，直到你停止它或關機。（實測過：從 Claude Code 啟動後關掉 Claude Code、雙擊啟動後直接按視窗的 X 關掉，Bot 都繼續在線。）- 已經在執行時再按一次啟動，只會顯示「已在執行中」，不會開第二個。
- 每次開機後要用 Bot，就先啟動一次。
- 桌面的檔案不見了：在 Claude Code 跟它說「重建 channelcollab 的桌面捷徑」，或重跑 `/channelcollab:setup`。0.1.5 以前建的舊檔名（「啟動 channelcollab Bot」等）重建時會換成新檔名。

### 交辦事情

在綁定的頻道輸入 **@你的Bot名稱** 加上要做的事，例如：

> @小華Bot 幫我整理這份企劃書的重點，條列三點

Bot 會從這則訊息開一個討論串來處理。之後在**討論串裡直接講話**就好，不用再 @。

- 討論串裡 @ 了別的 Bot：只有被 @ 的 Bot 會回。
- 沒 @ 任何 Bot：只有開這個討論串的 Bot 會回。

### 訊息上的表情

| 表情 | 意思 |
|---|---|
| 👀 | 收到了 |
| ⚙️ | 處理中 |
| ⏳ | 排隊中，或在等某人按權限按鈕／回答問題（同時會有一則帶按鈕的訊息） |
| ✅ | 完成 |
| ❌ | 失敗 |
| ⏹️ | 被 🛑 停止了 |

### 權限確認（只有主人能按）

Bot 要改檔、執行指令，或讀取工作資料夾以外的檔案時，會在討論串 @ 主人，說明它想做什麼（例如要執行的指令、要改的檔案和改動內容），並附三個按鈕：

| 按鈕 | 意思 |
|---|---|
| **允許** | 只放行這一次 |
| **這個 session 一律允許 <工具>** | 放行，而且這個討論串之後同一種工具都不再詢問（例如所有指令）。Bot 重啟後仍然有效 |
| **拒絕** | 會跳出一個小視窗，可以填理由（選填）。Bot 會照理由調整做法 |

- **只有 Bot 的主人能按**，因為是在主人的電腦上執行。其他人按了只會看到「只有 Bot 擁有者可以核准」（不會跳出 PIN 視窗，也不會算進輸錯次數）。
- **設了 PIN 時**，主人按「允許」或「一律允許」會跳出小視窗要輸入 PIN。PIN 對了才放行；之後 **30 分鐘內**再核准不用重打（Bot 重啟後要重打）。按「拒絕」、🛑、回答選擇題都不用 PIN。
- **PIN 連續輸錯 3 次會鎖定**：整隻 Bot 暫停，所有 @、私訊都不理，直到主人回到電腦雙擊「**解除 <Bot 名稱> 鎖定**」（或重啟 Bot）。
- 讀取工作資料夾裡的檔案不會問。

**主人不在時（稍後核准）**：權限按鈕送出後，主人 **2 分鐘**內沒按，Bot 不會乾等：

1. 這個動作先跳過，排進「待核准清單」；Bot 先把不需要權限的部分做完，做不到的整理成「待主人核准」回報。
2. Bot **私訊主人一張卡片**：哪個討論串、誰提的需求、每個待核准動作的內容，按鈕「全部允許」「逐項選擇」「全部拒絕」（允許一樣要 PIN）。主人關閉了伺服器成員私訊時，卡片改發在討論串裡，一樣只有主人能按。
3. 討論串裡只會有一則短通知：「⏳ 有 2 個動作等 @主人 核准（已私訊主人）」。
4. 主人按「允許」後，Bot 自動回到討論串接著做，只放行清單上那幾個動作（內容一樣才放行），做完回報；通知改成「✅ 主人已核准」。按「全部拒絕」時通知改成「🚫 主人拒絕了…」，Bot 下次不會做這些動作。
5. 卡片 **24 小時**內有效，過期後按鈕失效。Bot 重啟或閒置關閉都不影響卡片。

**頻道設成自動模式（`auto`）時**，大部分動作由 Claude Code 自己判斷安不安全，判斷沒問題就直接做、不會跳按鈕。只有被自動模式擋下的動作才會出現上面的權限按鈕，訊息會多一行「🤖 自動模式擋下了這個動作，原因：…」。

- 按 **允許**：這個動作會照原樣真的執行（Bot 會再試一次，這次直接放行）。
- 按 **這個 session 一律允許 <工具>**：這個討論串之後同一種工具都不再經過自動判斷，直接執行。範圍很大（例如所有指令），請確定再按。
- 按 **拒絕** 或逾時：Bot 會照你的理由換個做法。

### 選擇題

Bot 需要人做選擇時，會發一則訊息，每個問題一個**下拉選單**（有的可以多選）。選單裡有「其他…（自行輸入）」，選了會跳出小視窗讓你自由輸入。所有問題都答完，Bot 才會繼續。提出需求的人和主人都可以作答；10 分鐘沒人答完，Bot 會當作沒有人回答。

### 🛑 停止這一輪

Bot 處理超過幾秒時，會出現一則「⚙️ 處理中…」的訊息，上面有 **🛑** 按鈕。按下去會馬上中斷這一輪（觸發訊息標 ⏹️），等待中的權限按鈕和問題也一併取消。之後在討論串繼續講話，Bot 還記得前面的對話。提出需求的人和主人可以按。

### 傳檔案

- **給 Bot**：在 @Bot 的那則訊息直接附上檔案或圖片（單檔 25MB 以內），Bot 會讀取，圖片也看得懂。只有觸發 Bot 的那則訊息的附件會交給它。
- **Bot 給你**：Bot 可以把工作資料夾裡的檔案（例如它整理好的文件）直接傳到討論串。

### 看細節

回覆底下的「📄 詳細」按鈕：看這一輪 Bot 做了哪些動作，只有按的人看得到。

### 討論串裡的指令（打 `/` 會跳出選單）

在討論串裡打 `/` 會跳出指令選單，例如 `/help`、`/stop`、`/status`、`/model`、`/plan`、`/compact`、`/retry`、`/skill`，限主人或提出需求的人（和 🛑 一樣）。也可以打 `!` 開頭的備用寫法（例如 `!help`，訊息只打指令才算）。說明見第 5 節的指令表。

- **同一個伺服器有好幾隻 Bot 時**，每隻 Bot 都有同名的指令，選單會依 Bot 分組（顯示 Bot 的名稱和頭像），**請選自己要找的那隻 Bot 底下的指令**。
- 不能用的時候（例如不是主人也不是提出需求的人、不在綁定頻道的討論串裡、不在白名單、PIN 鎖定中），Bot 會回一則**只有你看得到**的說明。
- `/status`、`/help` 的結果只有你看得到；`/model`、`/plan`、`/stop`、`/compact`、`/retry`、`/skill` 會改變對話，會在討論串留一則簡短紀錄。

### 常用指令（在 Claude Code 裡輸入）

| 指令 | 用途 |
|---|---|
| `/channelcollab:status` | Bot 有沒有在跑、登入成誰、綁了哪些頻道、最近的錯誤 |
| `/channelcollab:start` | 啟動 Bot（和雙擊桌面的「啟動」一樣） |
| `/channelcollab:stop` | 停止 Bot（和雙擊桌面的「停止」一樣） |
| `/channelcollab:bind` | 綁定更多頻道、改模型或工作資料夾、開關私訊 |
| `/channelcollab:roster` | 管理自己的名冊：把常合作的人和 Bot 加進來（只要 Discord ID）、列出、移除 |
| `/channelcollab:guidelines` | 看 Bot 的協作守則 |

### 停止時要注意

停止時 Bot 會結束進行中的工作再退出（做到一半的那一輪會標 ❌）。**不要用工作管理員直接結束 node**，那樣不會正常收尾。

## 5. 私訊 Bot（在手機上直接跟自己的 Claude 講話）

私訊 Bot 就像在手機上用一個簡化版的 Claude Code：不用 @、不用開討論串，直接傳訊息就好。**只有主人能私訊自己的 Bot**，別人私訊只會收到一句「這隻 Bot 只接受主人私訊」。

### 怎麼開

1. 先設定 PIN（雙擊桌面的「設定 <Bot 名稱> PIN」，或在 Claude Code 說「設定 channelcollab 的 PIN」）。**沒設 PIN 時私訊一律不開放**。
2. 在 Claude Code 說「幫我開 channelcollab 的私訊，工作資料夾用 D:\某個資料夾」，或執行 `/channelcollab:bind`。
3. 在 Discord 點自己的 Bot →「傳送訊息」。第一次（以及每隔 30 分鐘）會先請你按「🔓 解鎖」輸入 PIN，解鎖後剛剛那則訊息會自動接著處理。（斜線指令在還沒解鎖時會回一個「解鎖」按鈕，解鎖後再用一次指令。）

**你和 Bot 要在同一個伺服器**：Discord 規定要有共同的伺服器才能私訊 Bot。團隊成員通常已經和自己的 Bot 在團隊伺服器裡；只用私訊的人見第 6 節。

沒開私訊時，私訊 Bot 只會收到「私訊未開啟」。

### 用起來和討論串一樣

狀態表情、權限按鈕（同樣要 PIN）、選擇題、🛑、附檔、長訊息自動切段都一樣。Claude 忙的時候再傳訊息會排隊，做完這一輪就接著處理。閒置一陣子後 Bot 會先關掉背後的程序，下一則訊息會自動接回同一段對話（第一則會慢 20～40 秒）。

### 指令

打 `/` 會跳出指令選單，選這隻 Bot 底下的指令就好（選單會依 Bot 分組）。每個指令也有 `!` 開頭的備用寫法，效果完全一樣；`!` 寫法要整則訊息**只打指令**才算（大小寫都可以）。

| 斜線指令 | `!` 備用寫法 | 做什麼 | 討論串也能用 |
|---|---|---|---|
| `/help` | `!help` | 列出指令（只有自己看得到） | ✓ |
| `/clear` | `!clear` | 結束目前的對話，下一則訊息開新的（舊的可以用 `/resume` 接回）。Claude 還在做事時要先 `/stop` | 只限私訊 |
| `/resume` | `!resume` | 跳出選單，列出最近約 10 段對話（私訊的，以及這隻 Bot 在討論串裡的），選一段接回。討論串的對話會**複製一份**來接，討論串本身不受影響，工作資料夾也用那個討論串的 | 只限私訊 |
| `/stop` | `!stop` | 中斷 Claude 正在做的這一輪（同 🛑） | ✓ |
| `/status` | `!status` | 工作資料夾、模型、權限模式、這段對話開了多久、花費、上下文用量、額度（只有自己看得到） | ✓ |
| `/model` | `!model`、`!model sonnet` | 選 haiku／sonnet／opus（斜線指令可以直接從選項選；不選就跳出按鈕）。馬上生效，不用重開 | ✓ |
| `/plan` | `!plan` | 切到計畫模式：Claude 只討論、不改檔也不執行指令。再用一次切回原本的模式 | ✓ |
| `/compact` | `!compact` | 壓縮上下文（把前面的對話整理成摘要），讓對話可以繼續 | ✓ |
| `/retry` | `!retry` | 把上一則訊息原樣再送一次（例如剛剛失敗了） | ✓ |
| `/skill` | `!skill <名稱> [參數]` | 執行 Claude Code 的 skill 或自訂指令（見下方） | ✓ |

**`/skill` 怎麼用**：打 `/skill`，在 `name` 欄位開始打字，會列出這個工作資料夾可以用的 skill 和自訂指令（例如你在 Claude Code 裡用 `/某個指令` 叫的那些），選一個；要給參數就填 `args`（選填）。Bot 會把「`/名稱 參數`」交給 Claude Code 執行。

- 清單來自這個工作資料夾**上一次開對話時** Claude Code 提供的內容。還沒開過對話時清單是空的，會提示「先傳一則訊息開始對話，之後就能選 skill」。
- 只列 skill 和自訂指令；Claude Code 內建、在這裡用不到的指令不會列（壓縮上下文請用 `/compact`）。只接受清單裡的名稱。
- `!skill` 不帶名稱會列出清單。
- skill 執行時用到的工具，**一樣要經過權限按鈕、PIN 和禁區**，不會因為是 skill 就放行。

**斜線指令的小提醒**

- Bot 每次啟動時會向 Discord 註冊這些指令（重啟不會重複）。剛註冊（例如剛更新到 0.1.6）時，Discord 可能要幾分鐘才會在選單裡出現；看不到時先用 `!` 寫法，或重開 Discord（電腦版可以按 Ctrl+R）。
- 斜線指令需要 Bot 被邀請時有 `applications.commands` 權限。依 Discord 官方文件，用 `bot` 權限邀請的 Bot 本來就會自動包含它，channelcollab 的邀請網址也一直有帶，所以已經在伺服器裡的 Bot 不用重新邀請。萬一選單一直沒出現，請管理員用 `/channelcollab:create-bot` 產生的邀請網址再邀請一次（**重新邀請不會把 Bot 踢出伺服器**）。
- 不能用的時候 Bot 會回一則只有你看得到的說明（例如「這隻 Bot 只接受主人私訊」）。

### 上下文和額度提醒

- **上下文**（Claude 能記住的對話量）：用到 **70%** 時會提醒一次；**85% 以後每則回覆最後都會多一行**「🧠 上下文 87%，可打 !compact」；**95%** 再提醒一次「快滿了」。用 `/compact`（`!compact`）壓縮或 `/clear`（`!clear`）開新對話後，用量掉下來就不再附。討論串也一樣。
- **額度**（Claude 帳號的用量上限）：用到 80%、95% 時各提醒一次，例如「⚠️ 5 小時額度已用 85%，約 14:30 重置」；用完時會說大約幾點重置。`/status`（`!status`）隨時可以看目前的額度（Bot 剛啟動、還沒跑過一輪時會顯示「未知」）。

### 安全提醒

**私訊 Bot 等於在遠端操作你自己的電腦。**

- **Discord 帳號務必開兩步驟驗證**（使用者設定 →「我的帳號」→「啟用兩步驟驗證」）。帳號被盜的人就能私訊你的 Bot。
- PIN 不要告訴別人，也不要和其他密碼相同。輸入 PIN 的小視窗**不會遮住你打的字**，在公共場所輸入時注意旁人。
- 手機遺失時，先在電腦上雙擊「停止 <Bot 名稱>」，再處理 Discord 帳號（見第 7 節）。

## 6. 只用私訊（個人遠端 Claude，不參與團隊頻道）

只想在手機或別台電腦上私訊自己的 Bot，把它當成「遠端用這台電腦的 Claude Code」，不參與團隊頻道，也可以。不用綁任何頻道，也不用名冊。

### 要準備的

| 項目 | 說明 |
|---|---|
| 一隻 Bot | 管理員給的**交付檔**；或自己建一隻（在 Claude Code 執行 `/channelcollab:create-bot`，選「只給自己私訊用」，它會一步步帶你在 Discord Developer Portal 建好，token 直接存進你的電腦） |
| **和 Bot 共同的伺服器** | Discord 規定你和 Bot 至少要在同一個伺服器，才能私訊 Bot。可以用**自己建的私人伺服器**（只有你一個人也可以）：Discord 左側按「**＋ 新增伺服器 → 自己建立 → 給我和我的朋友**」，取個名字就好。自己建的 Bot 由你自己邀進這個伺服器（create-bot 會產生邀請網址，權限是 0，因為私訊不需要伺服器權限），不用找管理員 |
| PIN | **必要**。沒有 PIN 私訊不會開放 |
| Discord 兩步驟驗證 | 強烈建議（見下方資安） |

### 怎麼設定

在 Claude Code 執行 `/channelcollab:setup`，用途選「**只用私訊（個人遠端 Claude）**」。精靈會依序：

1. 檢查 Node、安裝執行環境（同第 3 節）；
2. 匯入交付檔，或沒有交付檔時改走 `/channelcollab:create-bot` 的「只給自己私訊用」；
3. 設定主人（你自己的 Discord 使用者 ID）；
4. **設定 PIN**（必要，不能跳過）；
5. 設定私訊的工作資料夾和權限模式（建議 `default`：改檔、執行指令都要在 Discord 按允許）；
6. 啟動 Bot；`/channelcollab:status` 會顯示「**模式：只用私訊**」，「綁定的頻道：無」是正常的；
7. 請你私訊 Bot 測一次（第一次會請你按「🔓 解鎖」輸入 PIN）；
8. 建立捷徑（「啟動 <Bot 名稱>」等）。

### 之後想加入團隊頻道

不用重新 setup。Bot 被邀進團隊的伺服器後，用 `/channelcollab:bind` 綁頻道就好（模式會變成「團隊頻道協作＋私訊」）。

### 資安

- **只有主人能用**：別人私訊 Bot 只會收到「這隻 Bot 只接受主人私訊」。
- **私訊等於遠端操作你的電腦**：能用私訊的人就能叫 Claude 讀檔、改檔、執行指令（改檔、執行指令一樣要按允許，設了 PIN 時要輸入 PIN）。
- **Discord 帳號一定要開兩步驟驗證**。PIN 不要告訴別人；連錯 3 次整隻 Bot 會鎖住，要回電腦解除。

## 7. 資安須知

### 有哪些風險

- **頻道裡的人能叫你的 Bot**：預設只有你和名冊上的人、Bot 能叫它（白名單），其他人 @ 它會被忽略。改檔、執行指令仍要你按允許。
- **自動模式（auto）下，讀檔和回覆不經過你**：Claude 判斷安全的動作會直接做，包括讀工作資料夾裡的檔案、把內容回覆到 Discord。
- **資料會貼到 Discord**：Bot 回覆的內容（可能包含程式碼、檔案內容）存在 Discord 的伺服器上，頻道裡的人都看得到。
- **token**：Bot 的 token 等於 Bot 的帳號密碼，拿到的人能冒充你的 Bot。它只存在你電腦的 `config.json`，不要分享這個檔案。
- **提示注入**：檔案、網頁或別人的訊息裡可能藏著「叫 Claude 做壞事」的文字。Claude 會盡量分辨，但不保證；所以改檔、執行指令仍要你核准，看清楚再按。

### 防護方式

- **兩步驟驗證**：Discord 帳號一定要開。
- **私人頻道**：綁定的頻道最好只開放給需要的人。
- **白名單**（預設開）：只有你和名冊上的人、Bot 能叫 Bot。
- **PIN**：核准權限和私訊都要 PIN；連錯 3 次整隻 Bot 鎖定。
- **禁區**：不管什麼模式、按什麼按鈕，Bot 都不能碰 channelcollab 自己的資料夾（含 token 和 PIN）、`.ssh`、`.env` 檔、Claude 的登入資料，也不能執行 channelcollab 的總控腳本。讀寫檔案的工具會準確擋下；執行指令（Bash、PowerShell）只能比對指令文字，是**盡力而為**，換個寫法仍可能繞過，所以執行指令前請看清楚再允許。

### 懷疑帳號被盜時

1. **先斷線**：在電腦上雙擊「停止 <Bot 名稱>」。
2. **救回帳號**：改 Discord 密碼、重設兩步驟驗證；到「使用者設定 → 裝置」登出不認得的裝置，到「已授權的應用程式」移除不認得的項目。
3. **換 token**：請管理員到 Developer Portal 重設 Bot 的 token（Reset Token），給你新的交付檔，重新匯入（`/channelcollab:setup`）。
4. **檢查 Bot 做了什麼**：看 `%USERPROFILE%\.channelcollab\bot.log`；在每個工作資料夾執行 `git status`、`git log`，看有沒有不認得的改動。
5. **通報 IT**。

### 誠實說明限制

- Bot 看不到對方的 IP 或裝置，只知道是哪個 Discord 帳號。帳號被盜時，Bot 分不出來，所以兩步驟驗證和 PIN 很重要。
- PIN 小視窗沒有遮罩。
- 禁區對指令（Bash、PowerShell）只能盡力比對。

## 8. 常見問題

**Q：@ 了 Bot 沒反應？**
先用 `/channelcollab:status` 看 Bot 有沒有在跑、那個頻道有沒有綁定。討論串和論壇貼文沿用上層頻道的綁定。沒在跑就 `/channelcollab:start`。

**Q：Bot 一直顯示 ⏳？**
它在排隊，或在等主人按權限按鈕、等人回答選擇題。主人是你的話，找到那則 @ 你、帶按鈕的訊息按一下。權限按鈕 2 分鐘沒按會改成「稍後核准」（私訊你一張卡片），Bot 先做其他能做的。

**Q：錯誤訊息說「Claude 沒登入」？**
在這台電腦開終端機執行 `claude`，照畫面登入後再試。錯誤訊息會附上原因的前幾行和建議怎麼做。

**Q：私訊 Bot 沒反應？**
`/channelcollab:status` 看「私訊」那一行：沒開就用 `/channelcollab:bind` 開；有「還沒設定 PIN」就先設 PIN。也確認你是用主人的帳號私訊，而且你和 Bot 在同一個伺服器（見第 6 節）。

**Q：打 `/` 看不到 Bot 的指令？**
Bot 剛更新或剛啟動時，Discord 可能要幾分鐘才出現；重開 Discord（電腦版 Ctrl+R）通常就有了。同一個伺服器有好幾隻 Bot 時，選單依 Bot 分組，往下找你的 Bot。還是沒有就先用 `!help`，並請管理員看 `bot.log` 有沒有「registered … global slash commands」。

**Q：`/skill` 的清單是空的？**
清單要等這個工作資料夾開過一次對話才有。先傳一則訊息給 Bot，等它回覆後再打 `/skill`。

**Q：被鎖定了（PIN 輸錯 3 次）？**
回到電腦雙擊桌面的「解除 <Bot 名稱> 鎖定」（0.1.5 以前建的捷徑叫「解除 channelcollab 鎖定」），在跳出的視窗輸入 y。`/channelcollab:status` 會告訴你檔案實際在哪裡；找不到檔案時會顯示要執行的指令。或停止再啟動 Bot。

**Q：別人在頻道 @ 我的 Bot 沒反應？**
白名單預設開：只有你和名冊上的人、Bot 能叫它。用 `/channelcollab:roster` 把對方加進名冊（只要 Discord ID）。

**Q：權限按鈕按了說「只有 Bot 擁有者可以核准」，但我就是主人？**
用 `/channelcollab:status` 看「主人 Discord ID」是不是你的 ID。不是的話，跟 Claude Code 說「把 channelcollab 的主人設成 <你的 Discord 使用者 ID>」。

**Q：setup 說「需要 Node 22 以上」？**
照第 1 節安裝 Node，然後**重開終端機和 Claude Code** 再試。

**Q：安裝執行環境失敗？**
多半是網路問題（公司網路或代理伺服器擋了下載）。換個網路再試，或聯絡管理員。

**Q：啟動時說 token 無效（401）？**
管理員可能重設過你的 Bot token。請管理員給你新的交付檔，再跑一次 `/channelcollab:setup`。

**Q：不小心把交付檔內容貼到聊天室了？**
馬上通知管理員重設 token（舊的就失效了），再用新的交付檔重新設定。

**Q：plugin 有新版本怎麼更新？**
在終端機執行：

```
claude plugin marketplace update channelcollab
claude plugin update channelcollab@channelcollab
```

重開 Claude Code 後，執行 `/channelcollab:stop`、再 `/channelcollab:start`，執行環境會自動更新。

**Q：設定和 log 放在哪裡？**
`%USERPROFILE%\.channelcollab`。`config.json` 裡有 token，**不要分享這個檔案**。`bot.log` 是執行紀錄，回報問題時可以給工程師看。

**Q：要花錢嗎？**
Bot 用的是你自己的 Claude 帳號額度。簡單的頻道可以把模型設成 haiku 省額度（`/channelcollab:bind`）。
